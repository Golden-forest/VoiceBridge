# VoiceBridge 移动端前端重设计

日期：2026-05-25

## 目标

对 VoiceBridge 移动端前端进行整体重设计，实现紧凑单页布局、温润质感视觉风格、基于使用频率的快捷指令自动置顶。

## 现状问题

1. **布局松散** — 当前所有功能从上到下堆叠成列表，需要滚动才能看到底部功能
2. **录音按钮过大** — 172px 高的大按钮占用大量空间，与紧凑使用场景不匹配
3. **快捷指令难找** — 7 个分组 19 个指令全部折叠在一个面板中，无法快速触达常用指令
4. **视觉风格朴素** — 缺乏统一的设计语言和精致感

## 整体布局

紧凑单页，所有核心功能在一屏内完成，无需滚动。从上到下顺序：

1. **顶栏** — 品牌 "VoiceBridge" + 窗口选择器 + 连接状态指示点
2. **最近指令区** — 最近使用过的快捷指令，标签形式横排（最多 6 个）
3. **文本输入框** — textarea，Enter 发送，Shift+Enter 换行
4. **操作按钮行** — 录音按钮（行内宽度）+ 撤销 + 回车
5. **折叠栏：更多指令** — 完整的分组指令面板
6. **折叠栏：常用语** — 常用语列表（含新增/编辑/删除）
7. **底栏** — 自动粘贴 toggle 开关 + 收藏按钮（有文本时出现）

## 视觉风格

温润质感（类似 Apple HIG）。

### 色彩体系

| 用途 | 亮色模式 | 暗色模式 |
|------|---------|---------|
| 页面背景 | `#faf9f7`（暖米白） | `#1a1918`（暖深灰） |
| 卡片/输入框背景 | `#ffffff` + 微阴影 | `#2a2928` |
| 文字主色 | `#1a1a1a` | `#f4f4f0` |
| 文字辅助 | `#78716c` | `#a8a29e` |
| 边框 | `#e7e5e4` | `#3b3938` |
| 强调色（录音/主按钮） | `#166534`（深绿） | `#22c55e`（亮绿） |
| 危险/录音中 | `#b91c1c`（深红） | `#ef4444` |
| 标签/折叠栏背景 | `#f0efeb` | `#252423` |

### 设计规范

- **圆角**：统一 8px（按钮/输入框），标签 6px
- **阴影**：极轻 `0 1px 3px rgba(0,0,0,0.04)`，不使用厚重阴影
- **字重**：品牌 700，正文 400，标签/小字 500-600
- **字体**：`-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`（保持现有）

### 关键视觉变化

- 录音按钮从 172px 大方块缩为行内按钮（~42px 高），录音中变红 + 脉冲动画保留
- 快捷指令标签风格统一：白底 + 暖灰边框，点击发送
- 窗口选择器样式跟随新色彩体系
- 折叠栏使用向右箭头 ▸，展开后旋转为 ▾，收起时显示数量如"常用语 (3)"

## 交互细节

### 1. 最近指令自动置顶

- 每次用户发送快捷指令时，记录到 `localStorage`（key: `voicebridge_recent_commands`），附带时间戳
- 置顶区显示最近使用的 6 个不重复指令
- 指令以截断短标签显示（最多 8 个汉字，超出省略号）
- 点击标签直接发送，不展开面板
- 置顶区下方是"更多指令"折叠栏，包含全部分组

### 2. 录音按钮

- **空闲态**：绿色背景，麦克风图标 + "录音"文字
- **录音中**：红色背景 + 脉冲动画，显示计时，文字变为"停止"
- **处理中**：灰色背景，显示"处理中…"，禁用点击
- 宽度为 `flex:1`，与撤销/回车并排

### 3. 文本输入框

- Enter 发送，Shift+Enter 换行，发送后清空
- 有内容时底栏出现"收藏为常用语"按钮
- 语音识别结果直接替换文本框内容（保持当前行为）

### 4. 折叠栏

- 点击展开/收起，箭头旋转动画（`transform: rotate(90deg)`）
- 展开后内容最大高度 200px，超出滚动
- 常用语折叠栏内保留：点击发送、长按编辑/删除、新增按钮
- 快捷指令折叠栏内保留：分组标签 + 标签列表

### 5. 连接状态

- 顶栏右侧小圆点：绿色=已连接、红色=断开、灰色=连接中
- 移除独立的"正在连接电脑端…"状态文字行
- 点击圆点触发 toast 提示，显示详细状态信息（如"已连接电脑端"或"连接已断开，正在重连..."）

### 6. 自动粘贴开关

- 从 checkbox 改为 toggle 开关样式
- 移到底栏右侧，更紧凑

## 文件变更范围

仅涉及前端三个文件：

- `src/public/index.html` — HTML 结构重构
- `src/public/style.css` — 样式全面重写
- `src/public/app.js` — 新增最近指令逻辑、toggle 开关、状态点，调整录音按钮逻辑

不涉及后端或桌面端代码。
