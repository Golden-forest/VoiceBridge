# VoiceBridge 手机优先扫码配对设计

**日期：** 2026-09-24  
**状态：** 已获用户方向批准，待实施

## 目标

把桌面客户端从“电脑、手机分别登录”改为“手机是唯一登录端”：

1. 电脑客户端启动后立即显示二维码，不要求输入邮箱或密码。
2. 手机扫描二维码，打开 `https://voicebridge.heyflint.top/app`。
3. 手机未登录时只在手机上登录一次；已登录时直接确认绑定。
4. 绑定成功后电脑自动上线，后续正常重启无需重新登录或扫码。

Cloudflare Pages 平台域名 `voicebridge-6kr.pages.dev` 只作为部署基础设施备用，不在客户端主流程中展示。

## 已验证的生产地址

- 正式网页：`https://voicebridge.heyflint.top/app`，2026-09-24 实测 HTTP 200，包含认证和配对入口。
- API 反代：`https://vb-api.heyflint.top`，用于 Supabase Auth、数据库、Realtime 和 Edge Functions。
- `https://heyflint.top` 根域名当前返回 520，不用于 VoiceBridge 二维码或登录跳转。

## 方案选择

采用现有的匿名桌面身份和一次性配对令牌：桌面只持有独立的运行时身份，手机登录真实账号后认领设备。真实账号密码和手机会话不进入二维码，也不传给电脑。

不采用“把电脑登录会话放进二维码”，因为二维码截图会变成账号凭据。废弃当前电脑、手机分别登录的双登录流程。

## 桌面端流程

1. 无有效运行时会话时，桌面通过 Supabase Anonymous Auth 创建并持久化匿名身份。
2. 桌面调用 `device-pairing` 的 `start` 动作创建十分钟有效的一次性配对令牌。
3. 二维码和兜底网址都指向：
   `https://voicebridge.heyflint.top/app?pairing_token=...&device=...`
4. 桌面轮询配对状态；手机认领后自动启动 Realtime 和允许的 LAN 能力。
5. 已成功绑定的匿名运行时会话在客户端重启后继续使用，不重复扫码。
6. 二维码过期或失败时显示明确错误，并提供“刷新二维码”。

桌面界面删除邮箱、密码和 OTP 登录表单。二维码旁保留：

- 明确文案“用手机相机扫码；账号只需在手机登录”；
- 正式手机网址；
- “复制网址”；
- “打开手机网页”；
- “刷新二维码”。

## 旧版本迁移

升级时若发现桌面保存的是旧的真实账号会话：

1. 使用旧会话把本机设备记录标记为 revoked，避免同一设备 ID 与新匿名运行时冲突；
2. 登出并删除旧桌面账号会话；
3. 创建匿名运行时身份并显示一次新的手机配对二维码。

迁移只影响桌面本地登录方式，不删除真实用户、订阅、管理员标记或手机会话。

## 权限与套餐

匿名桌面不能直接读取真实账号的 profile 或 subscription。`device-pairing` 增加经过运行时身份校验的状态动作：

- 只允许查询 `runtime_user_id` 等于当前匿名身份的设备；
- 返回是否已认领、真实 `user_id` 和归一化套餐 `free | pro | admin`；
- 不返回邮箱、支付信息或其他账号资料。

桌面据此判断是否启动会员 LAN 能力。管理员仍得到 `admin` 权限。

## 手机端流程

手机打开带配对令牌的 `/app`：

- 未登录：先展示现有登录页，登录成功后继续展示绑定确认；
- 已登录：直接展示设备名称和“允许并绑定”；
- 成功：显示“电脑已连接”，清理地址栏中的配对令牌；
- 过期：提示回到电脑刷新二维码；
- 冲突：明确提示该电脑已绑定其他账号，并指引在电脑端重新配对。

## 错误处理

- 匿名登录失败：桌面显示网络错误和重试按钮，不退回密码登录。
- 二维码生成失败：保留重试入口和具体可读错误。
- 二维码过期：停止旧轮询，刷新后使用新令牌。
- 旧会话迁移失败：不破坏旧会话，显示可重试错误。
- 网络断开：沿用现有 Realtime 退避重连；配对状态不丢失。

## 验证

自动化测试覆盖：

1. 无会话时创建匿名身份并进入配对模式；
2. 桌面不再渲染账号密码登录入口；
3. 二维码固定使用 `https://voicebridge.heyflint.top/app`；
4. 手机登录后可以认领匿名桌面；
5. 匿名桌面只能读取自己的绑定状态和套餐；
6. 管理员认领后桌面获得 admin 套餐；
7. 旧真实账号会话安全迁移；
8. 二维码过期、刷新和设备冲突；
9. 客户端重启后保持绑定；
10. 全量单元测试和 hosted PWA 构建通过。

手动验收覆盖 macOS 桌面客户端与手机浏览器完整扫码流程，并检查控制台无明显错误。
