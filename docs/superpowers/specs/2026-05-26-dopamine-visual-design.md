# VoiceBridge 多巴胺视觉升级设计

## 目标

将当前"温暖极简"的前端视觉升级为"苹果级质感 × 多巴胺配色"，在保持功能布局不变的前提下，通过色彩、渐变、阴影和微交互提升视觉品质和愉悦感。

## 设计方向

- **质感参考**：苹果官网 — 细腻阴影、微妙层次、精致排版
- **色彩策略**：暖橙主色 + 点缀色，饱和但不刺眼
- **背景处理**：微妙渐变 + 卡片质感叠加（非纯色，非花哨纹理）
- **动效级别**：苹果级微交互（弹性按压、平滑过渡、hover 反馈）
- **约束**：不卡通、不赛博朋克、不花哨，保持专业感

## 组件设计

### 页面背景

从纯色 `#faf9f7` 改为微妙暖橙渐变：

```css
background: linear-gradient(165deg, #fffbf5 0%, #fff5eb 40%, #fef7f0 100%);
```

方向 165deg（近垂直偏左），从极淡暖白过渡到淡橙再回来，营造温暖的呼吸感。

### 卡片（输入区、面板）

- 白色背景 + 暖色阴影：`box-shadow: 0 2px 12px rgba(200,120,50,0.08), 0 1px 3px rgba(0,0,0,0.04)`
- 半透明白色边框：`border: 1px solid rgba(255,255,255,0.8)`
- hover 时阴影加深：`0 4px 20px rgba(200,120,50,0.12), 0 1px 4px rgba(0,0,0,0.06)`
- 圆角保持 16px

### 按钮层次

**次要按钮**（粘贴、撤销、回车）：
- 白色背景 + 极淡边框
- `box-shadow: 0 1px 4px rgba(0,0,0,0.04), 0 0 0 1px rgba(0,0,0,0.06)`
- 按压时：背景变为 `#fef9f4`，缩放 `scale(0.92)`
- 过渡：`transition: all 0.2s cubic-bezier(0.34, 1.56, 0.64, 1)`

**主要按钮**（发送）：
- 渐变橙背景 + 发光阴影
- `box-shadow: 0 2px 10px rgba(232,121,58,0.3)`
- hover 时：阴影扩大 `0 4px 16px rgba(232,121,58,0.4)`

**录音按钮**：
- 渐变橙圆形 + 光晕
- `box-shadow: 0 4px 16px rgba(232,121,58,0.35)`
- 录音中切换为红色 + 脉冲动画（保持现有行为）

### 品牌 Logo

盾牌图标从深绿改为暖橙渐变，带暖色阴影光晕，增强品牌辨识度。

### 设备状态栏（Device Pill）

- 背景：`#fff5eb`
- 文字：`#c2410c`（深橙）
- 连接点：`#e8793a` + `box-shadow: 0 0 6px rgba(232,121,58,0.4)` 微光效果

### 最近指令标签（Recent Tags）

- 默认：白底 + 极淡阴影（与卡片一致）
- 首个/活跃标签：`#fff5eb` 底 + `#e8793a` 文字

### Tab 栏

- 背景：`rgba(255,255,255,0.6)` + `backdrop-filter: blur(8px)` 半透明毛玻璃
- 激活 tab：白底 + 阴影 + 主色文字
- 非激活 tab：弱化灰色文字

### 快捷指令按钮（Quick Grid）

- 默认：白底 + 淡阴影
- 常用/高亮：`#fff5eb` 底 + `#e8793a` 文字 + `border: 1.5px solid rgba(232,121,58,0.15)`

### 常用语列表

- 整体保持白底卡片风格
- 长按编辑态的视觉反馈用暖橙强调
- 底部弹窗保持底部抽屉式，增加毛玻璃背景

## 微交互动效

### 按钮弹性缩放

所有可交互按钮 `:active` 时应用弹性缩放：

```css
transition: all 0.2s cubic-bezier(0.34, 1.56, 0.64, 1);
/* :active 时 */
transform: scale(0.92);
```

cubic-bezier(0.34, 1.56, 0.64, 1) 产生轻微的回弹过冲效果，是苹果常用的弹性曲线。

### 卡片 hover

卡片/按钮 hover 时阴影从低到中过渡：

```css
transition: box-shadow 0.3s ease;
```

### Tab 切换

保持现有的 0.15s 过渡，改为同时过渡背景和阴影。

### 录音按钮脉冲

保持现有脉冲动画，阴影颜色改为暖橙光晕。

### Toast 通知

保持现有 0.2s 淡入淡出，背景改为暖橙渐变或白底+暖橙左边框。

## 不改动项

- 功能布局结构（单列垂直布局不变）
- HTML 结构和语义
- app.js 功能逻辑
- commands.json 数据
- 响应式断点和 clamp() 流式尺寸
- 录音模块的行为（55s 上限、计时器等）
- WebSocket 通信逻辑
- 常用语 CRUD 功能

## 实施范围

仅修改 `src/public/style.css`，所有改动通过 CSS 变量 + 选择器覆盖实现。不新增 HTML 元素，不修改 JS 逻辑。暗色模式同步更新所有变量。
